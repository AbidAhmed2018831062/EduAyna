Project Overview

This project is a student management dashboard created with Next.js and Express.js. This project allows users to view, add, edit or delete students. Redux Toolkit is used to manage student data, loading and error states, search, and filters. Student information is stored in PostgreSQL and accessed through REST API endpoints. It has mainly these features:
1. View and Edit Students
2. Add and delete students
3. Search, Sort and Filter Students
4. View Individual Student page


Frontend Tech Stack: Next.js, JavaScript, Redux, TailwindCss
Backend Tech Stack: Express.js, PostgreSQL

No need of installing or cloning the website to run it have shared live links. 

But to run locally:

Fronted Developepment: npm run dev
Fronted Production: npm run build

Backend Development: npm run dev
Fronted Production: npm start

No need of anything for database it is an online databased hosted on render.
