Project Overview

This project shows students management dashboard with 

Frontend Tech Stack: Next.js, JavaScript, Redux, TailwindCss
Backend Tech Stack: Express.js, PostgreSQL

No need of installing or cloning the website to run it have shared live links. 

But to run locally:

Fronted Developepment: npm run dev
Fronted Production: npm run build

Backend Development: npm run dev
Fronted Production: npm start
