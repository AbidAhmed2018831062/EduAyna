# Student Management Dashboard

## Project Overview

This project is a student management dashboard created with Next.js and Express.js. This project allows users to view, add, edit, or delete students. Redux Toolkit is used to manage student data, loading and error states, search, and filters. Student information is stored in PostgreSQL and accessed through REST API endpoints.

It has mainly these features:

1. View and Edit Students
2. Add and Delete Students
3. Search, Sort, and Filter Students
4. View Individual Student Page

## Tech Stack

### Frontend Tech Stack

* Next.js
* JavaScript
* Redux
* Tailwind CSS

### Backend Tech Stack

* Express.js
* PostgreSQL
